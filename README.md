# David Cotter — Portfolio & CV

A responsive, accessible personal portfolio website built with HTML, CSS and vanilla JavaScript.

## Preview locally
Open `index.html` in a browser. Click **View / Print CV** to open `cv.html`; use the browser's print dialog to save a PDF.

## Before publishing
- Add a public email address to the contact section (`index.html`) and CV (`cv.html`).
- Add LinkedIn profile URL, if desired.
- Review and confirm all job titles, employment dates, qualification names, project descriptions and CV content.
- Add actual project screenshots and live demo links when ready.
- Optionally replace the abstract DC graphic with a professional photo.

## Publish with GitHub Pages
1. Create a public GitHub repository named `david-cotter-portfolio`.
2. Upload all four files to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, `main`, `/ (root)` and save.
4. Your URL should become `https://trxdave.github.io/david-cotter-portfolio/` once GitHub Pages deploys.

No external JavaScript dependencies, backend, analytics or credential collection. The email link uses `mailto:` and has no server-side contact form.
